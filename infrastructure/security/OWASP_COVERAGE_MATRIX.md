# OWASP Security Coverage Matrix — Glacier

**Date**: 2026-04-30
**Version**: 1.0
**Standards**: [OWASP Web Top 10 (2021)](https://owasp.org/www-project-top-ten/) · [OWASP API Security Top 10 (2023)](https://owasp.org/API-Security/editions/2023/en/0x11-t10/)

## Scope Statement

This matrix covers all HTTP and STOMP/WebSocket endpoints exposed by Glacier.
The **authoritative endpoint list** is maintained by
[`EndpointInventoryTest.java`](../../src/test/java/de/seism0saurus/glacier/security/EndpointInventoryTest.java)
(UT-sec-06, `AUTHORITATIVE_ENDPOINT_ALLOWLIST`). Any undocumented HTTP endpoint fails CI.
STOMP destinations are defined by `WebSocketConfiguration.java`.

See [`SECURITY_TESTS.md`](SECURITY_TESTS.md) for how to run these tests locally.
