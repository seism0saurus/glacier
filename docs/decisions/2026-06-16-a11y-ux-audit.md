# Decision Record: Accessibility & Usability Audit

Date: 2026-06-16
Phase: Audit
Auditors: ux-ui-designer (4 parallel read-only audits — global shell+wall, toot+share-dialog, share-viewer, cross-cutting)
Status: Findings accepted; remediation sequenced below

## Summary

Comprehensive WCAG 2.2 AA + Nielsen-heuristic audit of the whole Angular frontend (~24 components across
the global shell, main wall, toot rendering, share dialog, share-viewer feature, and the GDPR/legal page),
plus a review of existing axe-core automated coverage. The app's a11y foundations are strong (see Strengths)
but the audit surfaced **one Critical functional/security-grade gap, a systemic German-source localization
inversion, gaps in the share-viewer's live semantics, and meaningful automated-coverage holes.**

Read-only audit — no code changed in this record. Remediation is tracked in the sequencing section and will
land in follow-up commits.

## Critical

### VIEW-01 — Revoke/expiry is never detected in FALLBACK mode
**WCAG 4.1.3 / 3.2.5 · Nielsen #1 · also a security/correctness gap**
`frontend/src/app/share/services/readonly-wall-stomp-client.service.ts` (polling path),
`frontend/src/app/share/components/readonly-wall/readonly-wall.component.ts:214-232`

Revocation/expiry reaches the viewer **only** via the STOMP socket (`transportMode$ → EXPIRED`). Once a
viewer degrades to FALLBACK polling, the poll response is deserialized purely as `ReadonlyTootView[]` with no
control-frame parsing, so a revoked link leaves the recipient on a frozen-but-live-looking wall: no assertive
announcement, no navigation to `/expired`. Breaks the security intent (revocation should be immediate) and the
accessibility announce-then-navigate, in exactly the degraded mode meant to keep users informed
(`glacier-fallback-mode-discipline`: behavior must hold in all transport modes).

**Fix direction**: detect link-no-longer-active on the polling path (the poll endpoint already returns 404 for
inactive links per the anti-enumeration contract — the frontend must treat that 404 like expiry) and route it
through the same component-owned announce-then-navigate path used for STOMP EXPIRED (single owner — do not
reintroduce a service-side `navigate`).

## Serious

### i18n / German-source-locale inversion (theme — multiple findings)
German is the declared source locale (`<html lang="de">`) and `main.ts` only ever fetches
`messages.en.json` (German comes from compile-time template defaults), yet many defaults are English and the
legal page is entirely English:

- **XCUT-01** (Serious) — `gdpr.component.html:4-435`: the entire ~128-block legal/Datenschutz text is
  hardcoded English with no `@@id`. German voice narrates English; legal exposure for a German operator.
- **XCUT-02** (Serious) — English template defaults shown to German users: `header.component.html:4`
  ("Glacier - The Mastodon Social Wall"), `footer.component.html:11` ("Legal Notice & GDPR"),
  `hashtag.component.html:58` ("Cancel All"/"Clear Toots"), `gdpr.component.html:1` (dialog title). Some sit
  beside German `aria-label`s → visible/accessible-name mismatch (WCAG 2.5.3).
- **XCUT-03** (Moderate) — `messages.de.json` is dead (loaded by nothing) and missing 11 keys vs en.
- **SHELL-03/04/05/13, TOOT-09, TOOT-10, TOOT-13, VIEW-04/07c/11** — scattered untranslated strings &
  formatting: hashtag form label/grid-aria/placeholder (`hashtag.component.html:4,6,46`), chip edit/remove
  aria concatenations (`:13,43`), footer body text (`footer.component.html:3,14`), logo alt
  (`header.component.html:3`), spinner `aria-label="Erstelle Link…"` (`share-dialog.component.ts:179`),
  poll "Stimmen gesamt" (`poll-ref.component.ts:44`); formal/informal register split ("Sie" source vs "du"
  catalog); date formatting uses browser locale not app locale (`share-dialog.component.ts:331`,
  `readonly-wall.component.ts:175`).

### SHELL-01 / SHELL-02 — Missing `<main>` landmark + non-functional skip link (Serious)
`app.component.html:8` — shell has no `<main>`; skip link targets `#toots`, which isn't focusable
(`tabindex="-1"`), so activation scrolls but doesn't move focus. The readonly viewer *does* have `<main>` —
inconsistent. Fix: wrap the wall in `<main id="main-content" tabindex="-1">` and repoint the skip link.

### Share-viewer live semantics (Serious)
- **VIEW-02** — `readonly-wall.component.ts:235-242`: announces on every `toots$` emission incl. initial
  catalog hydration → false "Neuer Toot von …" for old toots on load; `@@share.feed.new-toots.announce`
  plural key exists but is unused. Fix: announce only genuinely-new arrivals; batch count; suppress initial.
- **VIEW-03** — `readonly-wall.component.ts:214-232`: no visible/announced transport-status (LIVE/PROBING/
  FALLBACK) on the viewer though the `TransportStatusSource` seam exists for it. Recipient can't tell live vs
  stalled. Fix: render a `role="status"` indicator bound to `transportMode$` reusing the main pattern.
- **VIEW-04** — `readonly-wall.component.ts:167-170`: `feedLabel` runs naive `.replace()` on an ICU plural
  that `$localize` does not expand → the feed `aria-label` can contain literal `{count, plural, …}` braces.
  Fix: compute the count branch in TS or run the ICU formatter; verify named-param substitution in the
  runtime catalog loader.
- **VIEW-05** — `cw-toggle.component.ts:23-45,71-82`: content-warning toggle may leak warned content to AT
  when collapsed, lacks `aria-controls`, and announces a preview of the spoiler text on expand (defeats the
  warning). Fix: add `aria-controls`; verify collapsed `<details>` body is out of the AT tree (gate with
  `@if (isOpen)` if it leaks); announce neutral "Inhalt eingeblendet/ausgeblendet"; drop redundant region
  `aria-label`.

### XCUT-08 — Automated a11y coverage gaps (Serious)
axe is well-configured (WCAG 2.2 AA tags, serious/critical gate) but does NOT scan: the GDPR dialog (highest
risk), header, footer, the share-create dialog states, the share-expired page, or an individual toot. Also
**XCUT-09** (Minor): `share-link-a11y.spec.ts:23-30` duplicates axe config inline and runs in all 5 projects
instead of chromium-only (3× CI waste).

## Minor & latent

- SHELL-11/12: dead `hashtag` field; no inline validation feedback for duplicate/empty tag; destructive
  "Cancel All"/"Clear Toots" with no confirm/undo.
- VIEW-10/12: skip-link targets lack `tabindex="-1"`; no empty-state message on a fresh viewer.
- SHELL-08/TOOT-05: target-size checks at 320px.
- **TOOT-12 (latent non-a11y bug)** — `toot.component.ts:43-64`: a global `message` listener is registered
  per iframe and never removed (leak), and the iframe DOM `id` is the bare UUID, so reconnect/re-render can
  produce duplicate ids and accumulating listeners. Route to `tdd-ddd-implementer`.

## Strengths (already done well)

- Reduced-motion handled at the animation-engine level (`NoopAnimationDriver`), not just CSS.
- Connection indicator: documented ≥7:1 contrast in every state, icon+label+color (no color-only meaning).
- Main wall live region correctly designed; suppresses initial "Live" announcement.
- Native `<button>`/semantic roles; `:focus-visible` rings throughout; decorative icons `aria-hidden`.
- `MatDialog` used correctly (focus trap, ESC, focus restoration); revoke confirmation exemplary (initial
  focus on Cancel, destructive styling) — satisfies WCAG 3.3.4.
- Toot content rendered with `dir="auto"` bidi defense; per-toot `<article role="group">` + `<h3>` + `<time>`.
- EXPIRED announce-then-navigate correctly component-owned, fires once, regression-tested — in the STOMP path.
- axe harness exemplary where applied (WCAG 2.2 AA tags, serious/critical gate, chromium-only cost decision).

## Remediation sequencing

1. **Critical first** — VIEW-01 FALLBACK revoke/expiry detection (security-adjacent; full test pyramid).
2. **Quick wins batch** (~12 low-effort/high-value): SHELL-07 drop duplicate live-region `aria-label`;
   SHELL-01/02 `<main>` + skip-link; TOOT-04 `aria-haspopup`; TOOT-09 spinner i18n; VIEW-04 ICU fix;
   VIEW-08 remove `role="alert"`; VIEW-09a `altText || null`; VIEW-05a `aria-controls`; VIEW-07c poll i18n;
   VIEW-10 `tabindex="-1"`; SHELL-09 hover contrast; XCUT-04 GDPR close i18n.
3. **i18n remediation pass** — XCUT-01/02/03 + scattered strings; decide `messages.de.json` fate; CI parity
   check; German authoring of GDPR.
4. **Viewer-a11y batch** — VIEW-02 live-region correctness, VIEW-03 transport indicator, VIEW-05 CW, VIEW-06.
5. **axe coverage expansion** — XCUT-08/09 (GDPR dialog, header/footer, share dialog states, expired page).
6. **Latent bug** — TOOT-12 iframe listener leak / duplicate ids.
7. **Theming** — XCUT-07 MD3 token migration + dark mode (larger, schedule separately).
