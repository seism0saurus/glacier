# MD3 Token Theming + System Dark Mode — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Glacier's legacy prebuilt Material theme + hardcoded hex with an MD3 `mat.theme()` system-token theme and a system-triggered (prefers-color-scheme) dark mode, with WCAG 2.2 AA contrast guaranteed by tokens and verified by axe in both schemes.

**Architecture:** A teal-seeded MD3 palette (generated via the `@angular/material:m3-theme` schematic) drives `--mat-sys-*` tokens in light + dark via `theme-type: color-scheme` + `color-scheme: light dark`. Brand surface/background tokens are overridden with `light-dark()` to keep Glacier's pale-cyan (light) / deep-teal-tinted (dark) identity. All component CSS + inline component styles migrate hardcoded hex to `--mat-sys-*` tokens; domain semantic colors (connection-status states, notices) get explicit `light-dark()` pairs preserving today's tuned light values. axe a11y e2e scans run in both light and dark.

**Tech Stack:** Angular 19.2, Angular Material 19.2 (MD3 `mat.theme()`), SCSS (Angular CLI bundled `sass`), Karma/Jasmine, Playwright + `@axe-core/playwright`.

**Spec:** `docs/superpowers/specs/2026-06-16-theming-md3-darkmode-design.md`

```ts
import { Page, expect } from '@playwright/test';
// (reuse the existing assertNoWcag22AaViolations + runAxeOnlyInChromium)

/**
 * Runs the WCAG 2.2 AA axe scan twice: once in light, once in emulated dark
 * (prefers-color-scheme: dark). Both must pass. Resets to light afterward.
 */
export async function assertNoWcag22AaViolationsLightAndDark(page: Page, selector?: string): Promise<void> {
  await page.emulateMedia({ colorScheme: 'light' });
  await assertNoWcag22AaViolations(page, selector);
  await page.emulateMedia({ colorScheme: 'dark' });
  await assertNoWcag22AaViolations(page, selector);
  await page.emulateMedia({ colorScheme: 'light' });
}
```

- **CI gates the contrast claim.** The dark-scheme axe scans run on the dockerized stack in CI (`-P RunE2ETest`); the local machine has known toot-delivery flakiness. If a dark semantic-state pair fails ≥4.5:1 in CI axe, adjust the dark hex (darken bg / lighten fg) per the Task 6/canonical table and re-commit.
